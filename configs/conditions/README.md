# Planner conditions

| Config | Paper label |
|---|---|
| `full.json` | Full |
| `no_capability_semantics.json` | No capability semantics |
| `no_parameter_semantics.json` | No parameter semantics |
| `no_structure.json` | No JSON Schema (also called no schema-constrained decoding) |
| `reduced_capability_info.json` | Reduced capability information (coarse reference; not in the Holm family) |

All five conditions use temperature 0. The Qwen2.5-14B formal runs used tag `qwen2.5:14b`.
